## Общее описание
Проект представляет собой серверное веб-приложение на языке Python с использованием фреймворка FastAPI, предназначенное для асинхронной генерации штрих-кодов в стандарте Code128 в формате SVG с сохранением результатов в файловой системе и реляционной базе данных SQLite.

## Структура проекта
- `src/` — исходный код проекта и утилиты командной строки.
- `tests/` — автоматические тесты.

## Команды для сборки и запуска
- Запуск утилиты командной строки (Этап 1):
  ```bash
  python src/cli.py --input data.txt --output ./output
  ```
- Запуск проверки кодстайла:
  ```bash
  black src/ tests/
  flake8 src/ tests/
  ```
